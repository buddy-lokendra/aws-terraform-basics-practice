# terraform-aws-practice

Terraform se AWS S3 bucket banane ka practice project.

## Kya banta hai
- S3 bucket
- Versioning enabled
- Public access blocked

## Files
- `providers.tf`: AWS provider
- `variables.tf`: variables
- `terraform.tfvars`: values
- `main.tf`: resources
- `outputs.tf`: outputs

## Run kaise kare
```bash
terraform init
terraform plan
terraform apply
terraform destroy
```
